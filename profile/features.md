## Features:
- Simple installation.
- Automatic start up and login.
- Speech activation and recognition.
- Able to analyse and interpret user requests.
- Able to build (and update) a plan of execution.
- Able to stream the user's screen to the server.
- Able to stream instructions, feedback, and explanations to display and speakers.
- Can securely store past interactions (a.k.a “memories”) either locally or in the cloud.
- Can use memories to understand facts about the user (like who their daughter is etc.), communication style, and level of help needed.

## Optional:
- Able to catch scams.
- Companion phone app.
